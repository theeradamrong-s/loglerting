Running the APP:
    1. Build and Run:
        type "cargo run" in terminal.
    2. The app opens with overview screen.
Screen:
    * Overview: shows current watched logs, entry count, and paused state.
    * Logs: live log viewer
        - Filter field filters incoming lines (Case Sensitive).
        - Keyword search shows only lines with keyword.
        - Pause/Resume and Clear button.
    * Settings: configure log file paths and save/load settings.

Practical Usage:
    1. Run the app
    2. Change file path in main.rs
    3. Set the file path in Setting page
    4. Filter wanted keyword
